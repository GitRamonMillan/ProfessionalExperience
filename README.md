# Mi trayectoria de desarrollo

Timeline web interactivo para presentar proyectos de desarrollo agrupados por año, cliente y tecnologías.

## Funciones

- Diseño adaptable para escritorio y móvil.
- Búsqueda por cliente, proyecto, descripción y tecnología.
- Tarjetas expandibles con los proyectos de cada cliente y sus tecnologías.
- Conteo de clientes/grupos y proyectos identificados.
- Acentos de color por década.
- Avatar enlazado al perfil público de GitHub.

La página es estática y no requiere dependencias ni proceso de compilación.

Para verla accede a https://gitramonmillan.github.io/ProfessionalExperience/ en un navegador.
